# STM32F103 光敏电阻摩斯码接收

手机后置闪光灯 → 光敏电阻分压 → PA0 / ADC1 → 亮暗计时 → 摩斯码字母 → 完整消息 → 串口调试 / ESP8266 HTTPS 上报。

目标芯片是 **STM32F103C8T6**，沿用模板的 **8 MHz 外部晶振、72 MHz 系统时钟**。2026-09-10 已增加按键切换 T、完整消息编号、SOS/HELP 蜂鸣报警、DS1302 和 ESP-01S HTTPS 网关。**当前完整接线、配置和操作说明见 [README_IoT.md](README_IoT.md)**；以下保留基础光通信接收部分的说明。连续 ADC 日志默认关闭，可用 `LDR_DEBUG_ADC=1` 恢复。

## 1. 接线

```text
STM32 3.3V ── 10kΩ固定电阻 ──┬── 光敏电阻 ── GND
                             │
                            PA0

STM32 PA9（USART1 TX） ── USB转TTL模块 RX
STM32 GND             ── USB转TTL模块 GND
```

- 使用 3.3 V 分压电路，PA0 电压保持在 0～3.3 V。
- USB 转串口使用 TTL 电平；本版不接收串口命令，PA10 可以不接。
- 当前默认按用户提供的“环境光 ADC 约 530、照射时约 430”配置：光越强，PA0 电压越低。上图是符合这一方向的分压接法示例。
- 现成光敏模块应接 **AO 模拟输出**，并确认供电、输出范围和变化方向；DO 不适用于本 ADC 电阻估算。
- 若接成 `3.3V → 光敏电阻 → PA0 → 10kΩ → GND`，光照时 ADC 升高，需要把 `LDR_BRIGHT_IS_HIGH` 改为 `1`。
- 阻值估算只适用于已知固定电阻的分压电路。AO 模块若有其他电阻或放大电路，ADC 解码仍可调整使用，但打印的 ohm 不代表真实阻值。

## 2. 第一次使用

1. 打开 `MDK-ARM/Template.uvprojx`，编译并用你自己的 ST-Link 下载。
2. 串口助手设置 **115200、8 数据位、无校验、1 停止位、无流控**。
3. 手机闪光灯先关闭，保持环境光稳定，再复位 STM32。
4. 等待 `[LDR] CAL OK`，再保持灭灯 120 ms，让解码器完成暗状态同步。默认总共约 1.2 秒。
5. “光语 Morse”将 **T 设为 60 ms**，选择 **发送一次**。先输入 `HELLO`，再点击 **开始发送**。
6. 手机近距离正对光敏电阻。先确认能接收，再增加距离或加快速度。

发送 HELLO 时应依次看到这些行（示例，不是真机记录）：

```text
[RX] H  ....
[RX] E  .
[RX] L  .-..
[RX] L  .-..
[RX] O  ---
[RX] <idle>
```

`[RX] <space>` 是单词间隔；`[RX] ? invalid=...` 表示非法码型或异常光脉冲。
`<idle>` 只表示较长时间没有光脉冲，方便观察，不代表经过校验的完整数据帧。每个字母在暗间隔达到 2 个点时长时自动输出，最后一个字母不需要下一次发送来触发。

## 3. 常用参数

集中修改 `Software/LdrReceiver_Config.h`，修改后重新编译下载：

| 宏 | 默认值 | 含义 |
| --- | --- | --- |
| LDR_MORSE_DOT_MS | 60U | 必须与 App 的基本时间 T（点时长）一致 |
| LDR_BRIGHT_IS_HIGH | 0 | 光更强时 ADC 更低；若光照时 ADC 升高则改为 1 |
| LDR_FIXED_RESISTOR_OHM | 10000U | 实际固定分压电阻，用于阻值估算 |
| LDR_ADC_REFERENCE_MV | 3300U | 参考电压，用于电压估算 |
| LDR_CALIBRATION_MS | 1000U | 环境光校准时长，期间手机灯必须关闭 |
| LDR_ON_DELTA_COUNTS | 60U | 归一化后相对环境基线的亮判定增量；当前方向对应原始 ADC 下降 60 |
| LDR_OFF_DELTA_COUNTS | 30U | 暗判定增量；当前方向对应原始 ADC 回升到距环境基线 30 以内 |
| LDR_EDGE_STABLE_MS | 3U | 新亮暗状态需要连续保持的时间 |
| LDR_DEBUG_ADC | 1 | 开启 ADC 原始值和电压/阻值诊断；改 0 关闭 ADC 诊断，保留解码和故障提示 |
| LDR_DEBUG_RAW_PERIOD_MS | 20U | 原始 ADC 值的串口输出间隔，单位 ms；允许 10～60000，不改变采样率 |
| LDR_DEBUG_PERIOD_MS | 1000U | 电压、阻值和亮暗状态的完整诊断间隔，单位 ms |

本版固定点时长，**不自动猜测发送速度**。不要只改变手机速度而不改变程序参数。
“点亮 60 ms、随后灭 60 ms”的参数填 60，不是 120；程序参数是单个点的亮灯时长。

## 4. 调试方法

默认从 1000 Hz 采样中每隔 20 ms 输出一个原始样本，校准期间也会输出。串口显示示例（非实测）：

```text
[ADC] t_ms=1020 raw=530
[ADC] t_ms=1040 raw=430
[ADC] t_ms=1060 raw=435
```

`raw` 是 ADC DMA 取得的原始 12 位整数，范围 0～4095，未经中值滤波、亮暗方向归一化或阻值换算。`t_ms` 是从本次采集启动开始的样本时间，单位 ms；DMA 分块交付和串口发送会有延迟，串口到达时间不作为光脉冲的计时依据。这是每 20 个采样点选取 1 点的调试输出，不是全部 1000 点/秒的波形记录；解码仍处理每个 1 ms 样本。

原有 `[LDR] adc=... norm=... mV=... R=... light=...` 每秒输出一次，解码结果继续使用 `[RX]` 前缀。输出都在主循环中完成，不在 ADC 中断中打印。需要减少显示量时增大 `LDR_DEBUG_RAW_PERIOD_MS`，或将 `LDR_DEBUG_ADC` 设为 `0` 后重新编译下载。

启动采集 1 秒环境基线，再用双阈值和 3 ms 去抖判定亮暗。`norm` 统一为“亮光数值更高”：`LDR_BRIGHT_IS_HIGH=1` 时等于滤波后的 ADC，当前默认 `0` 时为 `4095 - 滤波后的 ADC`。中值滤波仅使用 3 个采样点。

按环境光原始 ADC 530 校准后，判亮阈值为 **≤470**，判灭阈值为 **≥500**，471～499 保持原状态，并经过上述中值滤波和去抖。校准时会打印 `[LDR] RAW: ambient=530 ON<=470 OFF>=500 (median ADC counts).` 便于直接对照原始数值。阈值随每次启动测得的基线变化，程序没有写死 530。60/30 是针对当前约 100 点亮暗差的初始设置，真实噪声和光敏电阻响应仍需实测确认。

- **只有 ADC，没有字母**：亮灯时 norm 要超过启动时打印的 on，灭灯时要低于 off。先调整距离、遮光和固定电阻，再考虑降低增量。
- **问号或错误字母很多**：确认手机手电筒发送模式、两端点时长匹配。检查灭灯后 ADC 是否及时恢复到环境基线；如需降速，同时将 App 和本配置改为 240 ms。
- **CAL FAIL**：环境基线过高，没有 ADC 余量。关闭手机灯、减弱环境光、检查分压方向或阻值，再复位。
- **环境光变化后不稳定**：手机灯关闭后复位重新校准。本版不自动追踪变化的背景光，避免把文字中的长亮误认作环境光。
- **dropped samples**：主循环未及时处理队列。不要额外加入长延时或大量打印。丢样后半个字符会丢弃，等暗间隔重新同步。
- **ADC/DMA error**：采集错误或停滞后停止采样并提示复位。停滞判断依赖 HAL 毫秒时基正常运行。

当前默认方向、且按上图分压电路接线时：

```text
V_PA0 ≈ ADC × 3300 / 4095  （mV）
R_LDR ≈ 10000 × ADC / (4095 - ADC)  （Ω）
```

ADC 达到 0 或 4095 时输出 `R=out-of-range`。阻值只是辅助诊断，**字母由亮暗时长决定，不是用固定阻值查表得到**。

## 5. CubeMX 和模块分工

打开 `Template.ioc` 查看、修改并重新生成配置。

| 配置 | 当前值 |
| --- | --- |
| ADC1 输入 | PA0 / IN0，12 位、右对齐、单通道 |
| ADC 转换 | 非连续、TIM3 TRGO 外部触发 |
| ADC 时钟 | APB2 / 6 = 12 MHz |
| ADC 采样周期 | 239.5 cycles |
| TIM3 | 72 MHz / (71+1) / (999+1) = 1000 Hz |
| TIM3 TRGO | Update Event，无定时器中断 |
| ADC DMA | DMA1 Channel1，循环、半字、内存递增、High |
| ADC DMA 中断 | 优先级 1；半满/全满各交付 32 个点 |
| USART1 | PA9 TX、PA10 RX，115200 8N1 |

- `Hardware/LdrAdc.c/.h`：ADC 校准、DMA 启停、样本队列和故障检查。256 槽队列容纳 255 个未读样本。先启动 ADC DMA，后启动 TIM3；停止顺序相反。
- `Software/LdrReceiver.c/.h`：环境校准、中值滤波、双阈值、去抖、阻值诊断、串口输出。
- `Software/MorseDecoder.c/.h`：纯亮暗时序解码，支持 A–Z、0–9 和 `+ = . , ? / -`，无 HAL 和动态内存。
- `Hardware/USART1.c/.h`：沿用模板的 printf 重定向。
- `Core` 外设配置由 CubeMX 生成，主程序调用在 USER CODE 区域。

资源所有权表见 `Docs/资源分配.md`。旧 H743、HMI、Software/My_ADC 和 Software/USART1 文件没有加入本 F103 构建；不要把 Software 中所有旧文件一键添加到 Keil。
