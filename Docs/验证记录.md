## CubeMX

- 使用本机 STM32CubeMX 6.18.0 加载并保存实际 `Template.ioc`，执行 `project generate`。
- 配置核对：PA0/ADC1_IN0、ADC 12 MHz / 239.5 cycles、TIM3 TRGO 1 kHz、DMA1 Channel1 循环半字、USART1 115200。
- 集成自定义模块后再次生成，17 个 main USER CODE 区内容均保留；CubeMX 仅将新增区域换行统一为 CRLF。
- GPIO、DMA、USART1、ADC1、TIM3 的 MX 初始化调用各一次，顺序保留。
- Hardware / Software 源文件和 Keil 组、包含路径保留，未将旧 H743 模块加入构建。

## Keil 完整构建

ARMCC：V5.06 update 5 build 528。目标：Template。

```text
Program Size: Code=10984 RO-data=1212 RW-data=48 ZI-data=4472
Template\Template.axf - 0 Error(s), 0 Warning(s).
```

- Flash 装载区域约 12 KB，RAM 区域 4520 字节，均在 F103C8 的 64 KB Flash / 20 KB SRAM 范围内。
- map 确认 `dma_samples` 位于 `0x200001BC`，128 字节；`sample_queue` 位于 `0x2000023C`，2048 字节。F103 无数据缓存，所在 SRAM 可由 DMA 访问。
- map 确认 main 调用 LdrReceiver / LdrAdc，解码器被链接，printf 的字符输出进入模板 Hardware/USART1.c 的 fputc。
- 固件：`MDK-ARM/Template/Template.hex`。
- HEX SHA-256：`2280AED87ACC22285471C62E28D1608B153C9A8B06C2A3A810704E836347153B`。

## 离线模块测试

从工程目录运行：

```powershell
.\Tests\run_decoder_tests.ps1
.\Tests\run_adc_tests.ps1
.\Tests\run_receiver_tests.ps1
```

脚本以主机 GCC 编译实际生产 `.c` 文件，ADC 测试替换 HAL，接收链路测试替换采样接口并捕获 printf；不会下载到单片机。脚本可通过 `-Compiler` 指定 GCC 或 Clang 的完整路径。

- 解码器：279 项检查通过。覆盖全部支持字符、60/120/240 ms、Morsify 5T 和标准 7T 词间隔、末字输出、非法码/长亮、毛刺、队列边界与时间回绕。
- ADC 模块：11 个场景、2368 项检查通过。覆盖校准、初始化契约、ADC DMA / TIM3 启停顺序与失败回滚、半满/全满、队列溢出、句柄过滤、停滞、时基回绕、中断插入时的统计快照、63/64 ms 覆盖边界；实际运行结果保存在 `adc_tests.log`。
- 接收链路：60/240 ms × 两种分压极性，56 项检查通过。覆盖 HELLO、ADC 噪声和尖峰、滞回、样本时间戳缺口、校准中断、采集故障停止、饱和输入及阻值公式。

独立审查发现并修复：读取 DMA 最后服务时间与当前 HAL tick 的中断竞态，以及 DMA 整圈 64 ms 覆盖边界。采样故障会停止接收；队列丢样则丢弃受影响半字符并重新同步。
