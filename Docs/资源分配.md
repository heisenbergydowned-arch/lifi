# 光敏电阻摩斯接收资源分配

| 资源 | CubeMX 初始化 | 运行时所有者 | IRQ / 回调 | 自定义启动顺序 |
| --- | --- | --- | --- | --- |
| GPIO / PA0 模拟输入 | MX_GPIO_Init、ADC MSP | LdrAdc | 无 GPIO 中断 | CubeMX 先初始化 |
| DMA1 Channel1，ADC1 | MX_DMA_Init、MX_ADC1_Init | Hardware/LdrAdc.c | DMA1_Channel1_IRQHandler → HAL DMA → ADC 半满/全满回调 | ADC 校准，先启动 ADC DMA |
| TIM3，1 kHz Update TRGO | MX_TIM3_Init | Hardware/LdrAdc.c | 无定时器中断 | ADC DMA 就绪后再启动 TIM3 |
| USART1 PA9/PA10，115200 8N1 | MX_USART1_UART_Init | Hardware/USART1.c | 保留模板 DMA4/5，本应用 printf 使用阻塞发送 | 外设初始化完成后才打印，ISR 不打印 |
| 原始样本转亮暗、诊断输出 | 无额外外设 | Software/LdrReceiver.c | 只在主循环执行 | 采集启动后处理样本 |
| 摩斯码点划、字母/数字解码 | 无额外外设 | Software/MorseDecoder.c | 只在主循环执行 | 参数中的点时长必须与 App 一致 |

`.ioc` 是外设配置来源；模块不重复调用 `MX_*_Init()`。
停止采集时先停止 TIM3，再停止 ADC DMA。
模板中的旧 Software/My_ADC、HMI 和 H743 文件不参与本 F103 目标构建。
